# Data

The production data used in the i-Neema Sales Intelligence project is intentionally not included in this repository.

The database contains business information relating to customers, products, sales transactions, and company performance. The actual data is therefore kept within the organization's controlled environment.

## Data Flow

The project uses the following data flow:

Google Sheets → MySQL (`iNeemaDB`) → Power BI → Power BI Service

## Repository Approach

This repository contains:

- Database schema documentation
- SQL queries used for analysis and data validation
- Power BI measures
- Project documentation
- Architecture and workflow documentation

Actual customer, product, and sales records are excluded from the public repository.

## Purpose

The project structure demonstrates the technical architecture, analytical approach, SQL development, Power BI implementation, and documentation practices without exposing confidential business information.
